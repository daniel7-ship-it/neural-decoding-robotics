# Replay timing contract — 2026-10-28, written before implementation

The stored 100 Hz electrode recording is converted into trailing 20-sample features at 100 ms decision spacing. Each stored `time` is the end of the last sample's 10 ms acquisition interval, not its start. At replay start T, the engine begins at the first feature with availability >=T. Prior gate state is reset; no earlier window is decoded. Playback elapsed time zero maps to recording time T; a window whose availability exceeds T is not decoded until that elapsed time has passed. Physics intervals are 20 ms. At each tick the old unexpired command is applied first; available windows may then be decoded. Newly issued commands are eligible from the following physics interval. If multiple windows become available during one tick due to an irregular recording, consume them in order and retain the last gated command; record each decision separately. The provided synthetic source normally has 100 ms spacing.

Gaps contain no invented windows. The previous command expires after its 250 ms TTL. Window times must be finite and strictly increasing; features must be finite two-dimensional rows with at least the decoder input width. Empty recordings complete immediately with zero applied command. A seek beyond the final availability completes immediately. One-window and final-window seeks decode at most that one window. A recording ends at the next expected decision interval after its last available window (100 ms for the current format); until then physics continues using expiring commands. At the end, apply zero velocity, finalize metrics, persist a completion trace, and remain complete until explicit restart. Repeated step calls after completion are idempotent. GUI rendering frequency never changes the replay clock.

On model/condition changes, interrupted runs are persisted as partial, then clock, command, gate, scoring and full robot/controller state reset. Completed block scores include the final block at completion; partial scores exclude the unfinished block. Prediction, gated issue and applied physics command are separate trace fields. Scoring labels live in the evaluator only, outside decoder/command inputs.
